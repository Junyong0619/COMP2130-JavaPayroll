# Java Payroll System (COMP2130)

A console-based payroll management system demonstrating core OOP concepts in Java.
This project was created individually for the COMP2130 course at George Brown College,
and is safe for public portfolio use.

## Features
- Multiple employee types (Salary, Hourly, Commission)
- Class inheritance & polymorphism
- Encapsulation through private fields & getters/setters
- Payroll calculation using ArrayList to manage multiple employees
- Separation of classes into Student, Address, GraduateStudent, etc.

## Technologies
- Java
- OOP (Inheritance, Polymorphism, Encapsulation)
- Collections (ArrayList)
- IntelliJ IDEA

## How to Run
1. Open project in IntelliJ IDEA or any Java IDE  
2. Navigate to `Main.java`  
3. Run the program — results print in console
